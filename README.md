# Live Chat Node 💬

A real-time live chat application built using Node.js and WebSockets. This project allows multiple users to join a chat room and communicate instantly.

## 🚀 Features
* **Real-time Messaging:** Instant message delivery without page refreshes.
* **Multi-user Support:** Multiple users can connect to the chat server simultaneously.
* **Responsive UI:** Clean design that works perfectly on both desktop and mobile screens.

## 🛠️ Tech Stack
* **Backend:** Node.js, Express.js
* **Real-time Communication:** Socket.io (or WebSockets)
* **Frontend:** HTML5, CSS3, JavaScript

## 📦 Installation & Setup

Follow these steps to run the project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/gojariyamahek-gif/live-chat-node.git
   ```

2. **Navigate into the project directory:**
   ```bash
   cd live-chat-node
   ```

3. **Install the required dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm start
   ```

5. **Open in your browser:**
   Open your browser and navigate to `http://localhost:3000`.
